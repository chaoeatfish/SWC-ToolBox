# 水力计算功能详细设计

## 依据规范
GB 51018-2014 水土保持工程设计规范 附录A.4 截排水设计

## 计算流程（按规范 A.4.2）

### Step 1: 汇水区域参数
| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 汇水面积 | F | km² | 用户输入 |
| 汇流长度 | L | km | 主沟长度 |
| 平均坡度 | J | ‰ | 沟道平均坡度 |

### Step 2: 汇流时间计算
采用公式：τ = 0.278 × L / v

其中 v 为汇流速度，根据地表类型查表确定（m/s）

汇流速度参考表（规范表）：
| 地表类型 | 汇流速度 v (m/s) |
|----------|-----------------|
| 草地 | 0.15 - 0.30 |
| 耕地 | 0.20 - 0.40 |
| 荒坡 | 0.30 - 0.50 |
| 裸露岩石 | 0.50 - 0.80 |
| 硬化地面 | 0.80 - 1.20 |

### Step 3: 设计重现期
根据规范要求，按工程等级选取：
| 工程等级 | 重现期 T (年) |
|----------|--------------|
| 1级 | 20 - 50 |
| 2级 | 10 - 20 |
| 3级 | 5 - 10 |
| 4级 | 5 |
| 5级 | 5 |

### Step 4: 暴雨强度计算
采用暴雨强度公式（各省/地区不同）：
q = 167 × A₁ × (1 + C × lgP) / (t + b)ⁿ

其中：
- q: 暴雨强度 (L/(s·hm²))
- P: 重现期 (年)
- t: 降雨历时 (min)，取 t = τ
- A₁, C, b, n: 地区暴雨参数（用户输入或查表）

用户需输入当地的暴雨强度公式参数，或直接输入暴雨强度值。

### Step 5: 设计径流量
Q = ψ × q × F × 10⁻³

其中：
- Q: 设计径流量 (m³/s)
- ψ: 径流系数（根据地表类型查表）
- q: 暴雨强度 (L/(s·hm²))
- F: 汇水面积 (hm²)

径流系数参考表：
| 地表类型 | 径流系数 ψ |
|----------|-----------|
| 草地 | 0.15 - 0.30 |
| 耕地 | 0.30 - 0.50 |
| 荒坡 | 0.40 - 0.60 |
| 裸露岩石 | 0.70 - 0.90 |
| 硬化地面 | 0.80 - 0.95 |

### Step 6: 排水沟断面设计
用户选择断面类型（矩形/梯形/抛物线形），输入参数后计算过流能力。

曼宁公式：Q = A × (1/n) × R^(2/3) × i^(1/2)

其中：
- n: 粗糙系数（根据砌体类型）
- i: 排水沟纵坡
- A: 过水断面面积
- R: 水力半径

### Step 7: 加高验算
- 计算排水量 ≥ 设计径流量
- 满足后加高：Δh = 0.2m 或 0.3m（用户选择）
- 最终沟深 H = 设计水深 + Δh

### Step 8: 断面参数计算
- 单位延米砌体体积 (m³/m)
- 单位延米抹面面积 (m²/m)
- 单位延米土方开挖量 (m³/m)

### Step 9: 导出 Excel
输出格式待用户确认，应包含：
- 汇水区域参数表
- 设计流量计算过程表
- 断面设计参数表
- 断面工程量表
