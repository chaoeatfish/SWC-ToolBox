# 1.设计标准
根据《水土保持工程设计规范》要求对截排水沟进行设计，工程等级选1、2、3级，2级、3级排水设计通过后断面尺寸要安全加高0.2m，1级要加高0.3m。
# 2.设计流量确定
根据《水土保持工程设计规范》（GB 51018-2014），截水沟排水流量采用小流域面积设计流量公式确定：
Qm=16.67φqF  
式中，Qm—设计洪峰流量（m3/s）  
q—设计重现期和降雨历时内的平均降雨强度（mm/min），利用标准降雨强度等值线图和有关转换系数，按式q=CpCtq5,10计算降雨强度；  
φ—径流系数，设定取值在0.15-0.95之间；  
F—山坡集水面积（km2），1/10000图上量算。    
# 3.设计重现期和降雨历时内的平均降雨强度按下式确定
q=CpCtq5,10
式中：q5,10—5年一遇10min短历时暴雨的标准降雨强度（mm/min），按工程所在地区查中国5年一遇10min降雨强q5，10等值线图，湖南地区取2.0-2.4；    
Cp—重现期转换系数，为设计重现期降雨强度 同标准重现期降雨强度 的比值，按工程所在地区，查GB51018-2014表A.4.1-2得，湖南地区取1.0，后续再深入取值选择。  
 Ct —降雨历时转换系数，为降雨历时t的降雨强度 同10min降雨历时的降雨强度 的比值,湖南地区1.0，后续再深入取值选择。

# 5.断面尺寸
根据计算出的排水沟设计流量，按明渠均匀流公式计算确定其断面尺寸：
Q=A\*C(R*i)^0.5       
式中：       A—排水沟过水断面面积，m2；
             C—谢才系数；
             R—水力半径，m；
             i—截（排）水沟沟底比降（3/1000～5/1000）
