# SWC Toolbox - 水土保持报告编制工具箱

供个人使用的水土保持报告编制工具箱，基于 Next.js 16 + React 19 + Tailwind CSS 4 构建，后续将通过 Tauri 2 打包为桌面应用。

## 技术栈

- **前端框架**: Next.js 16 (App Router) + React 19
- **样式**: Tailwind CSS 4
- **图表/图标**: @phosphor-icons/react
- **动画**: motion (framer-motion)
- **Excel 处理**: xlsx
- **桌面打包**: Tauri 2（已配置，未启用构建）

## 启动

```bash
pnpm install
pnpm dev
```

浏览器访问 http://localhost:3000

## 功能模块

### 工作台 `/`
工具入口卡片 + 最近使用列表，快速跳转各功能模块。

### 项目建设特性表 `/project-profile`
管理项目建设基础数据，为其他功能模块提供数据源。
- 支持创建多个特性表并命名、重命名
- 表结构：防治分区 | 占地面积 | 土石方开挖 | 土石方回填 | 项目自身利用方 | 综合利用方 | 弃方
- 平衡校验：开挖 - 回填 = 自用 + 综合 + 弃方
- 数据模型为可扩展列定义系统，新增字段只需追加列定义
- 数据持久化至 localStorage

### 进度图 `/progress`
项目施工进度甘特图。
- 支持月/季度切换
- 支持导出 PNG 和 Excel

### 水力计算 `/hydraulic-calc`
依据 GB 51018-2014 附录A.4 截排水设计规范，进行排水沟水力计算。
- **多沟渠管理**：左侧沟渠列表，支持新建、重命名、删除、切换
- **暴雨强度计算**：q = Cp × Ct × q5,10，支持手动输入参数
- **设计洪峰流量**：Qm = 16.67 × φ × q × F，支持 km²/hm² 双单位输入
- **地表类型选择**：16 种地表类型下拉选择，自动填入径流系数参考值
- **断面设计**：矩形/梯形/抛物线形，梯形支持边坡比下拉选择（1:0.25~1:1.5）
- **砌体参数**：砖砌/浆砌石/混凝土/土质/种草，自动填入壁厚、底板厚、糙率
- **安全加高**：按工程等级（1级0.3m，2/3级0.2m）
- **回填经验系数**：1.00~1.20 可选
- **自动计算**：谢才系数（曼宁公式）、流速、流量、过流验算
- **总览表格**：所有沟渠核心参数对比视图
- **导出 Excel**：两张表——排水沟计算参数表 + 排水沟单位工程量表
- 数据持久化至 localStorage

### 流失量计算 `/erision-calc`
水土流失量预测计算（待开发）。

### 指标对比分析 `/indicator-compare`
水土保持指标变更对比分析。
- 支持 53 号令和 14 号文两套标准切换
- 表头：条款 | 条款说明 | 原水土保持方案 | 变更方案 | 变化情况 | 是否涉及一般变更 | 是否涉及重大变更
- 原方案和变更方案手动输入，变更类型由系统自动判断（阈值规则 + 关键词匹配）
- 同条款自动合并显示

### 措施体系图 `/measure-system`
导入 Excel 措施体系表，自动生成 Draw.io 措施体系框图。
- 支持列：一级分区、二级分区、三级分区、工程措施、植物措施、临时措施
- 自动生成 Draw.io XML 格式框图，层级布局 + 连线
- 支持保存/加载模板
- 下载 .drawio 文件后用 Draw.io 打开编辑、导出 PNG

## 项目结构

```
src/
├── app/
│   ├── page.tsx                    # 工作台首页
│   ├── layout.tsx                  # 全局布局（侧边栏 + 主内容区）
│   ├── globals.css                 # 全局样式 + CSS 变量
│   ├── project-profile/            # 项目建设特性表
│   ├── progress/                   # 进度图（甘特图）
│   ├── hydraulic-calc/             # 水力计算
│   ├── erision-calc/               # 流失量计算
│   ├── indicator-compare/          # 指标对比分析
│   ├── measure-system/             # 措施体系图
│   └── settings/                   # 设置
├── components/
│   ├── Sidebar.tsx                 # 侧边栏导航
│   └── gantt/                      # 甘特图组件
├── lib/
│   ├── hydraulicCalc.ts            # 水力计算逻辑（GB 51018-2014）
│   ├── ditchModel.ts               # 排水沟数据模型
│   ├── projectProfile.ts           # 特性表数据模型
│   ├── parseMeasureExcel.ts        # 措施体系 Excel 解析
│   └── generateDrawio.ts           # Draw.io XML 生成
└── src-tauri/                      # Tauri 桌面应用配置
```
